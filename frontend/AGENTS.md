# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

This app is pinned to Expo SDK 54 (see `package.json`) — do not assume
v56+ APIs (`Color` from expo-router, `@expo/ui`, `NativeTabs`) are
available. An SDK bump is deliberately out of scope until the
runtimeVersion/EAS Update mismatch from the last upgrade attempt is
understood (a fresh `eas build` is required right after any SDK bump,
not just `eas update`).
